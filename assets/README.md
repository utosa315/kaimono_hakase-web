# 画像アセット

## 実アセット（アプリと同一）
- `icon-1024.png` / `icon-512.png` / `icon-192.png` / `apple-touch-icon.png` / `favicon.png` — アプリのランチャーアイコン（黒背景に博士サメ＋黄色い値札）。アプリ側 `assets/app_icon/kaimono_hakase_icon.png` から生成。
- `icon-foreground.svg` — 背景透過の博士サメ（AppBar と同じ素材）。ヘッダーのブランドマークに使用。

## サイトアイコン
- `sites/*.webp|png` — アプリと同じ各サイトのアイコン（アプリ側 `assets/*_icon.*` からコピー）。各社の商標であり、リンク先を示す目的でのみ使用する。

## 生成画像（Codex CLI の image_gen で 2026-09-06 に生成済み。作り直すときは同じ指示で）
すべて博士サメ（黒白シルエット、黄色い値札）の世界観に合わせる。写実ではなくフラットなイラスト。背景は `#fbf8f2`（サイトの紙色）か透過。

| ファイル | サイズ | 用途・内容 |
|---|---|---|
| `hero.png` | 1200×900（4:3、透過推奨） | ヒーロー右側。博士サメが虫眼鏡で複数のショップ（カート・値札・段ボール）を見比べている図。文字は入れない |
| `og.png` | 1200×630 | SNS共有用（OGP）。左に博士サメ、右に「かいもの博士」と「1つのキーワードで、全部のサイトを巡回。」。日本語のみ |
| `feature-sites.png` | 600×400 | 「9サイトを順番に巡回」の挿絵。ボタンが縦に並び矢印で順に開いていく抽象図。サイトのロゴは使わない |
| `feature-filters.png` | 600×400 | 「絞り込みを1回設定すれば全サイトに」。トグルとスライダーの抽象図 |
| `feature-favorites.png` | 600×400 | 「お気に入りと履歴」。星とメモ付きカードの抽象図 |
| `feature-noads.png` | 600×400 | 「広告なし・計測なし」。スマホの中に×印の付いたバナー、を柔らかく |

注意：各ECサイトのロゴ・商標は生成画像に含めない（サイトカードのアイコンはアプリと同じ実アイコンを別途使用）（アプリ内のアイコンは各社の利用条件に基づく表示であり、LPの装飾には使わない）。
