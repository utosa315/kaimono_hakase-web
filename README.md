# kaimono_hakase-web

「かいもの博士」の公式サイトです。

公開URL: https://kaimono-hakase.tardigrader.com

- `/privacy/` — プライバシーポリシー
- `/terms/` — 利用規約

## LPの運用

トップページは日本語・英語対応のブラウザ検索ツールです。検索語・条件は端末内でURLに変換し、利用者が選んだサイトを新しいタブで開きます。Enterは検索先へのフォーカス移動のみで、IME確定時には何もしません。

`landing.css` はトップページ専用です。法律文書の表示は既存の `styles.css` を使用します。`assets/app-search.png` はAndroidエミュレーター上の実画面（開発版、サンプル商品名）です。

2026-09-06時点でGoogle Play掲載URLは404のため、主導線はブラウザ検索です。公開を確認したら `#app` にストアボタンを追加してください。存在しない掲載ページへ誘導しないでください。

Web検索はアフィリエイト情報を付けず、アクセス解析も行いません。収益化の次の作業は、各プログラムでWeb媒体の登録・承認状況を確認し、承認済み媒体に対応するリンクと広告表記を整えることです。アプリ側もリリースビルドの設定確認が必要です。成果は各プログラムの確定報酬で評価し、送客クリックだけを売上として扱わないでください。

アプリ公開後はストアで訪問・インストール、アフィリエイト管理画面で送客・確定成果を確認します。独自の利用計測を導入する場合は、検索語を送らない設計とし、プライバシーポリシーを実装に合わせて更新してください。
